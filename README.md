# 知识库

个人知识管理系统，收集整理技术文章、学习笔记和实践经验。

## 目录结构

```
.
├── README.md
├── ai/                          # AI/LLM 相关
│   ├── agents/                  # Agent 框架与实践
│   ├── claude/                  # Claude 系列工具
│   ├── llm/                     # 大语言模型通用知识
│   └── prompts/                 # Prompt 工程
├── architecture/                # 系统架构
├── dev-tools/                   # 开发工具
├── engineering/                 # 工程实践
├── frontend/                    # 前端开发
├── backend/                     # 后端开发
├── database/                    # 数据库
├── devops/                      # DevOps/运维
├── reading/                     # 读书笔记
└── misc/                        # 其他
```

## 使用方式

- 按主题分类存放
- 每篇文章保留原始出处和作者信息
- 定期整理归档
