## 什么是 Prompt Packs

Prompt Packs 是 OpenAI Academy 提供的即用型提示词集合，由 OpenAI 的资深专家为不同角色设计，帮助用户学习新知识、开启新职业、更自信地应对生活。

## 核心特点

1. **即用型**：复制粘贴即可使用，每个提示词都配有明确的"So What?"说明其价值
2. **可定制**：替换方括号 `[...]` 中的内容，附加需要参考的文件或链接
3. **多输出格式**：支持要点、一页简报、面向公众的摘要等多种输出格式
4. **安全审查**：所有输出都是草稿，需要经过专家判断、法律、隐私、记录管理和可访问性审查

## 使用方法

### 基础步骤

1. **概述任务**：明确需要 ChatGPT 做什么
   - 示例：总结上季度的项目参与数据，并为下季度建议政策或运营调整

2. **提供上下文**：添加有助于理解的背景信息或文档
   - 示例：使用我们提交给卫生服务部的 Q2 外联和注册报告中的数据

3. **描述理想输出**：告诉 ChatGPT 希望的响应格式
   - 示例：写成正式的执行摘要格式

### 进阶技巧

- **指定输出风格**：要点、一页简报、面向公众的摘要
- **附加参考材料**：上传电子表格、报告或链接
- **审查每份草稿**：在分享前检查准确性、适用性和合规性
