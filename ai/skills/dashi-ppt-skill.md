# 大师 PPT Skill (dashi-ppt-skill)

- **仓库地址：** https://github.com/chuspeeism/dashi-ppt-skill
- **类型：** AI Agent Skill
- **用途：** 把文档丢给 AI Agent，自动生成浏览器可编辑的 PPT，改完可一键导出 HTML / PDF / PPTX

## 核心特性

- **12 套视觉主题** — 预览选择，可随时整套更换
- **1020 个版式页面** — 图表、分析模型、卡片、目录等
- **8576 个可调控件** — 浏览器内直接编辑，所见即所得
- **导出格式：** HTML、PDF、真实可编辑的 PPTX

## 支持的 AI Agent

- Claude Code
- Codex
- Marvin
- Workdudy
- Dumate
- Qclaw
- OpenClaw

## 技术栈

HTML Deck (浏览器渲染) + PPTX 导出，不依赖 Python PowerPoint 库，直接生成原生可编辑 PPTX。
