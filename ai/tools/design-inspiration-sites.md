## 1. Awwwards

- **网址**：https://www.awwwards.com/
- **定位**：被称为「网页设计奥斯卡」，每日收录全球优质网站，从多维度（设计、可用性、创意、内容）打分。
- **适合**：找网页**视觉参考**、观察当下顶级设计趋势。
- **备注**：获奖作品往往在排版、动效、交互上有很强示范性。

## 2. React Bits

- **网址**：https://reactbits.dev
- **仓库**：https://github.com/DavidHDev/react-bits
- **定位**：开源、可复用的 **React 交互动效组件库**，支持自定义。
- **用法**：可直接复制代码，或复制其配套提示词交给 AI 生成。
- **适合**：给 React 项目快速加文字动画、粒子背景、互动卡片等。
- **详见**：[网页动效宝藏站点合集（5 个）](./web-motion-sites.md) 中的更详细介绍。

## 3. MotionSites

- **网址**：https://motionsites.ai
- **定位**：面向 **AI 编程**的动态网页模板站，有大量动效案例和现成 Prompt。
- **用法**：挑中心仪的动效页面 → 复制整段提示词 → 粘贴到 AI 建站工具里生成网站。
- **适合**：用 Lovable / Bolt / Cursor / Claude 建站时一键补足动效。
- **详见**：[网页动效宝藏站点合集（5 个）](./web-motion-sites.md)。

## 4. GitHub Trending

- **网址**：https://github.com/trending
- **定位**：GitHub 热门开源项目榜单。
- **筛选**：可按**时间**（Today / This week / This month）和**编程语言**筛选。
- **适合**：找**开发思路**、跟踪社区热点技术。

## 5. Product Hunt

- **网址**：https://www.producthunt.com/
- **定位**：全球新兴 AI 工具、产品社区，每日上新。
- **适合**：挖掘**产品创意**、观察工具类产品的包装与定位方式。

## 6. Indie Hackers

- **网址**：https://www.indiehackers.com/
- **定位**：独立开发者交流社区，分享个人项目、收入故事与经验。
- **适合**：找**个人项目灵感**，了解独立开发者的实战路径。

---

## 附：AI Website Cloner（配合 Codex 使用）

- **定位**：输入网址，AI 就能**拆解并重建页面**，方便学习与复刻。
- **用法**：配合 **Codex** 使用，输入目标网址 → AI 分析结构 / 样式 → 生成可参考的复刻代码。
- **适合**：想学习某个网站的实现方式，或快速搭出相似结构做二次创作。

## 使用建议

- **找视觉参考**：Awwwards → 记录喜欢的版式与动效 → 用 MotionSites / React Bits 落地。
- **找开发 / 产品灵感**：GitHub Trending（技术趋势）+ Product Hunt（产品形态）+ Indie Hackers（个人项目路径）。
- **学习复刻**：AI Website Cloner + Codex 拆解参考站，再**加入自己的小巧思**。
- ⚠️ **参考只是灵感**，核心是加入自己的想法与细节，不要纯搬运。
