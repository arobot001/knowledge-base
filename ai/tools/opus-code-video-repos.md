# Claude Opus 5.5 纯代码视频 GitHub 仓库合集

> 收藏日期：2026-10-21 | Star 数为收藏时约值

核心思路：不依赖视频生成模型，让 Claude Opus 5.5 直接写代码（p5.js / Three.js / Remotion 等）渲染出成片。提示词和源码大多公开，适合照着拆解学习。

## 1. awesome-opus5-5-videos（约 7.1k star）
- **地址：** <https://github.com/yihui-dev/awesome-opus5-5-videos>
- **简介：** 目前最大的爆款视频合集，每条都附上了背后的提示词，并配有 Skillry 上的实时复刻对照。

## 2. lemo-opuscar（约 4.4k star）
- **地址：** <https://github.com/lemomo-ai/lemo-opuscar>
- **简介：** 一个 Claude Code skill，装上之后挑一种风格，就能做出纯代码短片，51 种风格随便选（含风格提示词 + 纯代码样片 + 导演与技术指南）。

## 3. pdoom-video（约 3.0k star）
- **地址：** <https://github.com/mexicat/pdoom-video>
- **简介：** 一支歌词卡拉 OK MV 的完整工程，本地就能渲出 4K60。TypeScript。

## 4. PDoomVideo（约 2.3k star）
- **地址：** <https://github.com/JohnHeibel/PDoomVideo>
- **简介：** 同一首歌的另一支 MV 源码，和第 3 个对照着拆，很有意思。JavaScript。

## 5. mg-styles-15（约 1.4k star）
- **地址：** <https://github.com/Vincentwei1021/mg-styles-15>
- **简介：** 15 种 MG 动效风格，成片、提示词、源码全都给。Python。

## 6. ClaudeAnimationBase（约 1.3k star）
- **地址：** <https://github.com/JohnHeibel/ClaudeAnimationBase>
- **简介：** 手绘卡通角色动画的起步包，p5.js + p5.brush，自带 Clawd 角色和 31 种表情，附模型使用指南。

## 7. awesome-claude-5-5-videos（约 560 star）
- **地址：** <https://github.com/athemeroy/awesome-claude-5-5-videos>
- **简介：** 视频工作流合集，每个案例都标了出处，Opus 的就有 301 个，Sonnet 案例单独标注。

## 8. opus-video-prompts（约 510 star）
- **地址：** <https://github.com/joeseesun/opus-video-prompts>
- **简介：** 中文案例，配上能直接复制的提示词，收录 54 个 Opus 5.5 代码渲染视频案例。

---

## 使用建议

- **想快速出片：** 先装 `lemo-opuscar`，选风格即用。
- **想拆技术细节：** 对照 3 和 4 两支同歌 MV 源码。
- **想找灵感/抄提示词：** 1、7、8 三个合集；中文优先看 8。
- **想做 MG 动效或角色动画：** 5 和 6。
