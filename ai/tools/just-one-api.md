# Just One API

## 简介

Just One API 是一个统一的数据服务平台，提供来自社交媒体、电商和内容平台的结构化数据 API。通过统一的入口点访问多个平台的实时数据。

- **官网：** https://justoneapi.com/en
- **API 文档：** https://docs.justoneapi.com/en
- **Python SDK：** https://github.com/justoneapi/justoneapi-python
- **API 调试文档：** https://justoneapi.apifox.cn/

## 支持的平台

覆盖国内外主流平台，包括但不限于：

- **社交/内容：** 小红书、抖音、微博、哔哩哔哩、微信公众号、知乎、豆瓣
- **电商：** 淘宝、天猫、京东、拼多多、亚马逊、Temu、Shopee
- **短视频/直播：** 抖音、快手、TikTok、TikTok Shop
- **其他：** 美团、大众点评、携程、贝壳（房产）、IMDb、Google 搜索、Facebook、Twitter、Reddit、YouTube、Instagram

## 核心特性

- **统一 API 入口：** 多平台数据通过同一接口获取
- **Python SDK：** 轻量级，支持同步和异步请求
- **MCP Server：** 为 Claude Desktop、Cursor、Cline 等 AI Agent 提供结构化 API 访问能力
  - `search_endpoints` - 按平台/关键词搜索可用 API
  - `get_endpoint_schema` - 查看参数和响应结构
  - `call_endpoint` - 调用 API 并返回结果

## 使用场景

- **电商监控：** 跨平台追踪商品价格、评价、库存
- **社媒舆情：** 分析小红书、抖音、微博上的品牌趋势和用户情绪
- **市场调研：** 实时市场数据和消费趋势
- **KOL 洞察：** 监控抖音星图、小红书蒲公英的达人表现
- **房产分析：** 贝壳等平台的房源和市场交易数据
- **品牌保护：** 识别未授权内容和监控品牌声誉
