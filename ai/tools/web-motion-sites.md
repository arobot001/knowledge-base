# 网页动效宝藏站点合集

> 一组做网页动效超好用的资源站，覆盖「动效提示词 → 现成组件 → 动画库源码」的完整链路。
> 特别适合用 AI（vibe coding，如 Cursor、Claude、Codex）建站时快速补足设计感。

| # | 站点 | 一句话定位 | 网址 |
|---|------|-----------|------|
| 1 | **Motion Sites** | 100+ 动效网站的现成 AI 提示词库，复制即用 | https://motionsites.ai |
| 2 | **React Bits** | 200+ 免费开源动画 React 组件 | https://reactbits.dev |
| 3 | **Uiverse** | 免费开源的 UI 组件库（纯 CSS/Tailwind） | https://uiverse.io |
| 4 | **Anime.js** | JavaScript 动画引擎（7 万+ stars） | https://animejs.com |
| 5 | **Aceternity UI** | React + Tailwind + Motion 高级组件库 | https://ui.aceternity.com |

---

## 1. Motion Sites

- **网址**：https://motionsites.ai
- **定位**：面向 Lovable / Bolt / Cursor / Claude 的高级网页提示词库，主打「复制、粘贴、上线」。
- **内容**：100+ 动效网站的现成提示词，涵盖 Hero 区、落地页、SaaS、作品集、3D 网站、动效背景等。
- **用法**：在站内挑中心仪的动效页面 → 复制整段提示词 → 粘贴到 AI 建站工具里生成网站。
- **备注**：部分内容需订阅 Unlimited；有 Animated Backgrounds、MCP、Academy 等子板块。

## 2. React Bits

- **网址**：https://reactbits.dev
- **仓库**：https://github.com/DavidHDev/react-bits
- **定位**：开源动画 React 组件合集，200+ 高质量、可交互、可定制组件与微交互。
- **分类**：Text Animations / Animations / Components / Backgrounds / Micro Interactions。
- **用法**：以「源码片段」形式分发（复制即用，而非纯 `npm install`）；每个组件支持 JS 或 TS，样式可选纯 CSS 或 Tailwind，也支持 CLI 安装。
- **适合**：想快速给 React 项目加文字动画、粒子背景、互动卡片的场景。

## 3. Uiverse

- **网址**：https://uiverse.io
- **定位**：最大的开源 UI 元素库之一，海量免费按钮、卡片、加载动画、开关等。
- **用法**：直接用 HTML/CSS 或 Tailwind 复制代码；社区可分享自己的组件。
- **适合**：需要现成、轻量、可复制的界面元素（不依赖 React）。

## 4. Anime.js

- **网址**：https://animejs.com
- **仓库**：https://github.com/juliangarnier/anime
- **定位**：老牌 JavaScript 动画引擎，GitHub 7 万+ stars，轻量且强大。
- **特性**：直观 API、灵活关键帧、内置缓动、CSS transform 混合、Scroll Observer（滚动联动）、高级 stagger 等。
- **用法**：`npm install animejs` 或 CDN 引入，用 JS 驱动 DOM / SVG / 对象的动画。
- **适合**：需要精细控制时间轴、滚动触发动画的原生 JS 场景。

## 5. Aceternity UI

- **网址**：https://ui.aceternity.com
- **定位**：面向落地页的 React 组件库，基于 React + Tailwind CSS + Motion。
- **内容**：200+ 生产级组件、区块和模板——116+ 免费动效组件、180+ 落地页区块、17 套 Next.js 网站模板。
- **用法**：复制粘贴即可；区块/模板支持 shadcn CLI 安装（部分需 All-Access Pass）。
- **适合**：搭建高设计感的 React / Next.js 落地页，含暗色模式。

---

## 组合使用建议

- **快速出整站**：Motion Sites（拿提示词）→ AI 建站工具生成 → Aceternity UI（替换高级区块）。
- **React 项目加动效**：React Bits（现成组件）+ Aceternity UI（高级区块）+ Anime.js（自定义时间轴）。
- **纯 CSS 轻量需求**：Uiverse 直接抄元素。
