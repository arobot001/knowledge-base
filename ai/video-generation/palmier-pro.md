# Palmier Pro 调研报告

> 调研日期：2026-07-26

## 概述

Palmier Pro 是一款 macOS 原生的 AI 视频编辑器，由 Y Combinator S24 批次的两人团队开发。核心创新：将 AI 生成直接内置到时间线中，并支持通过 MCP 服务器让 Claude、Codex 等 agent 直接操作编辑器。

- **官网：** https://www.palmier.io/
- **GitHub：** https://github.com/palmier-io/palmier-pro
- **开源协议：** GPLv3（编辑器和 MCP 服务器开源，生成管线闭源）
- **当前版本：** 0.3.5（截至 2026 年 6 月底）

## 核心特性

### 1. 时间线内置生成
- 在时间线上直接生成图片、视频、音频片段
- 每个片段保留 prompt、模型、参考图等元数据，方便后续重新生成
- 支持首尾帧锁定、参考图风格一致性控制

### 2. Agent 驱动编辑器
- 本地 MCP 服务器，可连接 Claude Desktop、Claude Code、Cursor、Codex
- Agent 能读取整个时间线并执行操作：生成片段、剪辑空白、重排片段、用新 prompt 重新生成
- 权限有边界：只能读写时间线结构，不能访问外部文件或推送导出

### 3. 多模型支持
一个信用额度通刷多个模型：
- Kling V3
- Seedance 2.0（字节跳动）
- Veo 3.1（Google）
- Grok Imagine（xAI）

### 4. 混合编辑
- 支持导入真实素材，与 AI 生成片段在同一个多轨时间线上混合编辑
- 导出格式：MP4（H.264 / H.265 / ProRes）、NLE XML（Premiere Pro / DaVinci Resolve）

## 定价

| 层级 | 限时价 | 正式价 | 说明 |
|------|--------|--------|------|
| 编辑器 | 免费 | 免费 | 多轨编辑、导出，无需登录 |
| Pro | $29/月 | $49/月 | 适合轻度生成使用 |
| Max | $69/月 | $99/月 | 重度用户，额度更大 |

> 注意：当前为限时发布价。信用点无公开单价，约 5,000 credits ≈ 333 张图片或 3-7 分钟视频，实际消耗因模型和分辨率而异。

## 优势

- ✅ 编辑器完全免费，功能不残缺
- ✅ 消除"生成器↔编辑器"来回倒文件的痛苦循环
- ✅ Agent 直接操作工具，是真正的新范式（非聊天框建议）
- ✅ 开源透明，MCP 权限边界清晰
- ✅ 支持 NLE XML 导出，不是单向门

## 劣势

- ❌ **仅支持 macOS 26 (Tahoe)**，Windows/Linux/Intel Mac 全部排除
- ❌ 早期版本（0.3.5），有 bug，功能不成熟
- ❌ 信用点计费不透明，无法精确预算
- ❌ 缺少调色、转场、动效、特效等高级编辑功能
- ❌ 现有定价为限时折扣

## 适用场景

| 情况 | 建议 |
|------|------|
| Mac + Tahoe 系统 + AI 视频工作流 | 免费编辑器必装，付费按产出量试水 |
| Mac 但未升级 Tahoe | 暂时跳过，等系统升级 |
| Windows / Linux 用户 | 暂不支持，等后续跨平台 |

## 与现有工具的关系

- 与 `video-editing-skills.md` 中的工具互补：Palmier Pro 是编辑器平台，其中的生成可以调用 Seedance 等模型
- MCP + Agent 架构思路值得借鉴：将工具暴露为 agent 可操作的接口，而非简单附加 AI 助手
